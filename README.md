# Space Invaders (Raylib)

A simple 2D arcade shooter built in C++ using the [Raylib](https://www.raylib.com/) library. 

## Controls
* **A / D** or **Left / Right Arrows**: Move Ship
* **SPACE**: Shoot
* **R**: Restart game (on Game Over)

## How to Play
To play the game without building from source, download the `.zip` file from the **Releases** tab on the right side of this page. Extract the folder and run `main.exe`.

## Building from Source
This project uses CMake. To compile it yourself, ensure you have a C++ compiler and CMake installed.

1. Clone this repository.
2. Open the project in your preferred IDE (like VS Code or CLion).
3. Build the project using the provided `CMakeLists.txt`.
4. Ensure `background.png`, `plane.png`, and `enemy.png` are placed in the same output directory as the compiled executable.
